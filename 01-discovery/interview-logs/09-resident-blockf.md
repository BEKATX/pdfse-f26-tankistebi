# Interview 09 · Resident, Block F 3rd Floor · (code name: Resident-F308)
**Week:** 4 · **Asker:** GU · **Logger:** AK · **Consent:** yes; notes only, no recording  **Real or practice:** real**Context:** 4th-year CS student living on the 3rd floor of Block F, does laundry mid-week. Following up on Interview 08's plan, we tested an early clickable mobile mockup to evaluate live machine countdowns and the manual issue report button.  
**Our prediction:** We are wrong if users find digital status dashboards unnecessary or if they trust automated countdowns without a manual error-reporting mechanism.

**Workaround:** Used to message roommates on lower floors to check the basement before heading down.  
**Cost:** 15–30 minutes of messaging friction and waiting; disrupted roommates' studying.  **Frequency:** Checks laundry availability twice weekly.  **Prediction check:** Confirmed. The live countdown eliminated guesswork, provided the page requires zero login friction.  **Surprise ★:** The resident insisted on a crowd-sourced "Report Incorrect Status / Machine Broken" button, pointing out that one untracked wash can destroy trust in the whole board.  **Commitment:** Agreed to participate in the upcoming live pilot on Block F's -1 floor.
